# Mimic

Mimic is a local-first page recreation assistant MVP. It turns page screenshots into structured page analysis and runnable React + Tailwind pages, with a staged path toward preview, revision, component reuse, and real project export.

## MVP1 Goal

Input a single screenshot, generate an `analysis.json`, produce a React + Tailwind page, and preview it locally.
